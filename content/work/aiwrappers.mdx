<Section title="What it does">
  Sheharyar Ishfaq built AIWrappers as a client project in 2025. AIWrappers lets someone without code turn a prompt into a product. They describe the tool they want, an agent designs it (the form, the instructions for the model, the colours and the copy), and it goes live on a subdomain or their own domain. They can keep it public, protect it with a password, or charge for it.

</Section>

<Section title="How it works">
  <Cards>
    <Card title="The creator agent">GPT-4o turns the description into the app's configuration, with one tool to design a logo. It is scoped to single-screen tools, input then output, and declines multi-page apps, games and dashboards.</Card>
    <Card title="One deployment, many domains">Middleware reads the hostname and serves the right app, for subdomains and custom domains alike. Custom domains are added and verified through the Vercel API.</Card>
    <Card title="Model routing">38 models from OpenAI, Anthropic, Google, Replicate and Fal, across text, image, video and audio. Each request is routed by model family, using the app owner's own encrypted API keys.</Card>
    <Card title="Paid access">Apps can be public, password-protected or paid. Stripe Connect sends each payment straight to the owner, and buyers get an access link by email, with no account to create.</Card>
  </Cards>

<Section title="Hard calls">
  <div>
    <HardCall number="01" title="Generate configuration, not code">
      The agent doesn't write code; it writes an app's settings: a form schema, a system prompt and a theme. Every app then runs on the same tested codebase, so a fix or a new model reaches all of them at once.
    </HardCall>
    <HardCall number="02" title="Owners bring their own keys">
      Each app owner connects their own provider keys, stored encrypted and used only for their apps. The platform never pays for someone else's inference, and owners keep control of their usage and costs.
    </HardCall>
    <HardCall number="03" title="A deliberately narrow agent">
      The agent only builds single-screen tools and says no to everything else. A smaller promise it can keep beats a general one it can't, and the refusal is written into its instructions.
    </HardCall>
  </div>
</Section>
